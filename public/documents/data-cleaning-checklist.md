# Data Cleaning Checklist

## Struktur Data

- Nama kolom sudah jelas.
- Tipe data sesuai: tanggal, angka, teks, kategori.
- Tidak ada kolom kosong yang tidak digunakan.

## Kualitas Data

- Cek missing value.
- Cek duplicate row.
- Cek format tanggal.
- Cek nominal negatif atau tidak wajar.
- Cek kategori yang tidak konsisten.

## Validasi Akhir

- Total data sebelum dan sesudah cleaning dicatat.
- Asumsi cleaning ditulis.
- Data siap digunakan untuk analisis atau dashboard.
