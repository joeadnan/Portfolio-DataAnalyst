# Dashboard User Guide

## Cara Membaca Dashboard

1. Lihat KPI card untuk ringkasan cepat.
2. Gunakan filter tanggal untuk memilih periode.
3. Baca trend chart untuk melihat kenaikan atau penurunan.
4. Lihat ranking untuk mengetahui produk, customer, atau channel terbaik.
5. Baca insight notes untuk memahami rekomendasi.

## Komponen Dashboard

- KPI Card: angka utama.
- Line Chart: perubahan dari waktu ke waktu.
- Bar Chart: perbandingan kategori.
- Table: detail pendukung.
- Filter: periode, produk, channel, segment.

## Prinsip Dashboard

Dashboard harus mudah dibaca, tidak terlalu ramai, dan langsung menjawab pertanyaan bisnis.
